Лабораторная ТРПП: signal-room

1. Открыть терминал в каталоге проекта.
2. npm install
3. npm start
4. В браузере: http://127.0.0.1:3102
5. Автоматические проверки: npm test
6. Файл Postman-API.json импортировать в Postman (параметр baseUrl задан).

Для учебной локальной работы. Данные хранятся в data/db.json.
Камеры и IoT-события моделируются; реальные видеопотоки не подключены.
Для интеграции MediaMTX требуется настроенный HLS/WebRTC адрес.
